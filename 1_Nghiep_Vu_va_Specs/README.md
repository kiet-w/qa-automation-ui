# Nhóm 1 — Nghiệp vụ và Specifications

Thư mục điều hướng cho toàn bộ nguồn nghiệp vụ và tài sản thiết kế kiểm thử.

| Shortcut | Nội dung | Quy tắc |
| :--- | :--- | :--- |
| `copy/` | Code sản phẩm công ty | Read-only tuyệt đối. |
| `specs/` | BR, AC, FSD, decisions, validation và component specs | Nguồn sự thật cho expected result. |
| `testcases/` | Test-case source of truth theo module/ticket | Markdown và Excel chuẩn 20 cột. |
| `test_specs/` | Executable Markdown specs | Chia `atomic`, `integration`, `uat`, `break_it`. |
| `uat/` | UAT plan và kịch bản theo `r<xx>` | Không để file UAT trôi nổi ở root `uat/`. |

Các mục trong thư mục này là shortcut tới vị trí chuẩn ở repository root. Không phải bản sao dữ liệu.
