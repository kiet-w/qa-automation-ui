❌ Cách cũ (Dễ hỏng & mất thời gian)

AI đọc chữ trong tài liệu rồi tự suy diễn selector. Khi dev đặt tên ID hoặc class khác với tài liệu, script chạy fail liên tục và tester mất 80% thời gian để debug sửa locator.

✅ Cách mới trên Bảng Trắng (Chính xác 100%)

AI gọi BSK mở web thật để trích xuất đúng cây DOM, ID và class thực tế. Sau đó mới sinh test Markdown ({Atomic, UAT, Break_It}). Playwright chạy tự động là Pass ngay lần đầu tiên!

💥 Nhánh Break_It ("Phá có kỷ luật")

Không chỉ test luồng ngoan ngoãn. Sinh kịch bản gỡ client validation, double click, bơm XSS / 10k ký tự, sập mạng 500 để bắt trọn 80% lỗi unhandled crash và duplicate charge!
